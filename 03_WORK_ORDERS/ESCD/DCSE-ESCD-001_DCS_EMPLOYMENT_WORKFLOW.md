# ESCD DCS EMPLOYMENT WORKFLOW

**Task ID:** DCSE-ESCD-001  
**Status:** IMPLEMENTATION CONTRACT

## Purpose

DCS Employment is a first-class ESCD mission because it directly supports DCS professional income. ESCD should treat active opportunities as governed revenue work, not generic notes.

## Opportunity lifecycle

`DISCOVER/RECEIVE -> VERIFY -> QUALIFY -> FIT ASSESS -> DECIDE PURSUE/HOLD/DECLINE -> PREPARE -> REVIEW -> APPROVE SUBMISSION -> SUBMIT -> VERIFY RECEIPT -> FOLLOW-UP -> INTERVIEW -> NEGOTIATE -> OFFER/DECLINE/CLOSE -> ARCHIVE/LEARN-CANDIDATE`

## Minimum opportunity record

- stable opportunity ID
- source/recruiter/client where known
- title and location/work arrangement
- engagement type and duration
- compensation/rate data and whether verified
- submission deadline
- recruiter contact and communication thread refs
- requirements/skills
- fit assessment with VERIFIED/LIKELY/UNKNOWN
- resume/package baseline used
- customization deltas
- submission status and receipt
- next follow-up date
- interview/offer state
- revenue relevance/estimated value only when grounded
- risks/conflicts/unknowns

## Pursuit decision

ESCD may automatically research, extract requirements, compare against baseline evidence, draft tailored materials, and recommend pursue/hold/decline. External submission, recruiter response, rate commitment, and interview scheduling remain approval-gated by default.

## Resume governance

Maintain baseline ingredients, chronology, layout conventions, voice, footer, and verified claims. Customization is additive/selective, not fabrication. Named technologies, results, certifications, clients, or achievements require supporting evidence.

## Follow-up rules

A submission creates a bounded follow-up/watch item. No repeated recruiter outreach without evidence or DCS-approved cadence. Lack of response moves to WAITING/WATCH rather than remaining in NOW.

## NBA integration

Employment items receive revenue relevance only when a real opportunity exists. Near-term deadlines, strong fit, verified compensation, and explicit recruiter/client action can increase priority. Speculative role browsing does not automatically outrank committed work.

## Closeout

Every opportunity closes with disposition: submitted/no response, rejected, withdrawn, interview, offer accepted/declined, duplicate, stale, or invalid. Preserve lessons as DDNA candidates only after provenance and contradiction review.

## Acceptance

Test new recruiter email intake, duplicate opportunity, missing rate, conflicting dates, resume customization without unsupported claims, approval-gated send, verified submission receipt, follow-up timer, interview scheduling gate, and closure.
