DCSE MVT-007 | Agent Orchestration

Agents can now be registered, assigned, routed, and recorded.

MVT-007 creates the first Supabase-backed orchestration layer for participating agents and models. The layer supports task assignment, parallel review, sequential handoff, event logging, and DCS-controlled authority.

Created Layer

Command Post orchestration structures

Registry

Agent Registry

Registers participating agents, model roles, allowed lanes, permitted actions, restricted actions, and source of authority.

Tasks

Task Registry

Tracks task title, lane, priority, status, assignment mode, assigned agent, handoff role, input refs, output refs, and policy flags.

Assignments

Many-Agent Routing

Supports one-to-one, one-to-many, many-to-one, sequential, parallel, and review-board orchestration patterns.

Events

Task Event Log

Records creation, assignment, completion, blocking, handoff, review, decision, and receipt events.

Dashboard

Orchestration View

Provides a Command Post dashboard surface for task status, assigned agent, handoff role, and review requirements.

Authority

DCS Control

Agents execute assigned actions. DCS remains final authority for approval, merge, release, and doctrine correction.

Operating rule

Agents do not communicate through uncontrolled backchannels. Agents coordinate through shared records: tasks, assignments, events, PRs, Tribunal receipts, and Supabase activity trails.
