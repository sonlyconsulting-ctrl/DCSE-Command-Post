Create `~/.config/coder/mcp-config.json`:
```json

    "supabase": {
      "url": "https://mcp.supabase.com/mcp",
      "auth": {"type": "oauth", "provider": "supabase"},
      "projects": [
        {"name": "DCSE-DDNA", "project_id": "uutpzaiqymyufljdgdaa"},
        {"name": "SC-Command-Post", "project_id": "nevgdyfpxdaloacuutal"}
      ]
    }
  }
}
```

### Option C: Environment Variables
