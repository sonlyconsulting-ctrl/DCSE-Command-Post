## 7. Git and Source Control

Git actions are allowed when they are clearly part of the authorized objective and all safety gates pass. Do not require a second approval for an already authorized, reversible, task-scoped operation.

1. Run `git status --short --branch`.
2. Confirm the active branch and remotes.
3. Review the exact changed files.
4. Scan for secrets, PS material, generated noise, archives, and unintended binaries.
