# Tribunal Inbox: Persistent Project Standards

These standards auto-load into future turns on this project.

## 1. Visual System & Copy Style
- Follow the established visual system for all outputs.
- **Copy Style:** Strictly NO em dashes (—) or en dashes (–).

## 2. Header / Footer Rules
- Enforce strict adherence to structural header and footer guidelines.

## 3. Known Bugs & Fixes
- **File Operations:** Standardize file view and delete workarounds.
- **Local Storage:** Follow established local storage patches.
- **Publishing / Bundler:** Adhere to publishing and build bundler fixes.
- **PDF Export:** Apply known PDF export bug resolutions.

## 4. Uniqueness & Content Rules
- Guarantee content uniqueness.
- Strict enforcement of content and phrasing rules.
