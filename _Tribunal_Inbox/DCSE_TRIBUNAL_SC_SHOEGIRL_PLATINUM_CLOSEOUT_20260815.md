## 6. Wix Embed Finding

The Wix HTML component on the Shoe Girl page is fixed at 615 pixels high. The application initially used an 860-pixel cinematic hero, causing desktop dead space, portrait scaling problems, nested scrolling, and a poor mobile first screen.

The application was corrected to:

- Fit the 615-pixel host viewport.
- Use a controlled portrait crop on desktop.
- Remove the white camera frame, `01`, and rolling indicator.
- Use a compact image-backed mobile hero.
- Wrap mobile navigation instead of producing horizontal scrollbars.
- Adapt tablet and desktop heights to the available viewport.

If long-scene nested scrolling remains objectionable, the Wix-side remedy is to enlarge the HTML component or implement dynamic height synchronization. The application cannot independently enlarge its parent Wix component.
