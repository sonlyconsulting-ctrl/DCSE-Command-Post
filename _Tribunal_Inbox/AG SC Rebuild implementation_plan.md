# Sonly Consulting (sc.com) Main Page Implementation Plan

This plan details the design and structural architecture for the flagship `sc.com` website. It implements the "Tech-Consulting First" positioning by highlighting Sonly Consulting's core systems architecture capabilities and grouping other lines under a sister ventures showcase.

## User Review Required

> [!IMPORTANT]
> - **The Split Architecture:** Sonly Consulting Core (AI readiness, systems governance) will be placed front and center. TSL (SQL rewards engine) and Mental Ingenuity (governance audit) will act as direct technical proof points. CTJ, Smoove Spots, and Verse Vault will be housed in a secondary "Sister Ventures from the Studio" section.
> - **Visual Tone:** Deep Navy (`#0A192F`), Polished Gold (`#D4AF37`), and Silver (`#C0C0C0`) style, featuring glassmorphic terminals and a 3D rotating gold logo.
> - **Linguistic Restraints:** Strict third-person posture (no "we/our/us/I" in public text) and zero em-dashes.

## Proposed Sections

### 1. Sticky Navigation & 3D Logo Header
*   **Header:** Sticky navy header with a 3D Y-axis rotating gold "S" logo.
*   **Nav Links:** Systems Consulting, Technical Proofs, Studio Ventures, Interactive Auditor.

### 2. Section 1: Hero (Tech-Identity First)
*   **Headline:** "Structure Precedes Scale."
*   **Positioning:** Enterprise systems governance, AI integration readiness, and PostgreSQL data migrations.
*   **CTAs:** "Initiate Readiness Audit" & "Review System Proofs".
*   **Interactive Panel:** A rotating "Dynamic Perspective" terminal flashing strategic wisdom quotes.

### 3. Section 2: Systems Architecture Consulting (SC Core)
*   **Core Pillars:** AI Functional Consulting, Legacy Modernization, and Enterprise Delivery.
*   **Visual Check:** Custom input/output schema cards demonstrating clear data mappings (e.g. IN: Legacy rules → OUT: Audited schemas).

### 4. Section 3: Technical Proof Points (MI & TSL)
*   **Tedo's Sports Lounge (TSL) Backend:** Highlight the SQL rewards engine, idempotency pipeline, and leaderboard database schemas.
*   **Mental Ingenuity Governance:** Compiles C-suite context briefs and risk-review alignment frameworks.

### 5. Section 4: Sister Ventures Showcase (CTJ, SS, Verse Vault)
*   **Curriculum (CTJ):** Highlights the Critical Thinker's Journey Architect Edition and workbook modules.
*   **Curation (SS):** Highlights local discovery and merchant maps.
*   **Gifts (Verse Vault):** Showcases the embedded scripture selector widget.

### 6. Section 5: Inline Structure Readiness Auditor
*   **Integration:** A functional interactive tool based on `readiness_audit.html` that lets visitors rate 5 core domains. It calculates overall readiness using the "bottleneck principle" (lowest score determines maturity).

### 7. Footer
*   Professional contact and copyright details.

## Verification Plan
1.  **Linguistic Scan:** Review all copy to ensure no em-dashes and no first-person pronouns.
2.  **Functional Auditor Test:** Verify the calculator script computes overall readiness using the minimum score rule.
3.  **Responsive Check:** Confirm the grid layouts stack cleanly on mobile.
