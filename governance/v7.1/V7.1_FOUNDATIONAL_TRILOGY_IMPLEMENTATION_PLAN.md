## Automatic approval conditions

A body of work advances automatically under the standing DCS Level 0 authorization when all conditions are true:

- acceptance criteria pass;
- independent reviewer disposition is APPROVE;
- GitHub and Supabase evidence reconcile;
- no unresolved critical or high-risk finding remains;
- no reserved stop gate is triggered;
- rollback or recovery procedure is documented;
- canonical source is read back from GitHub after publication.

## Reserved stop gates

Stop for DCS Level 0 only for:

- production or public release;
- destructive database or filesystem operations outside an approved procedure;
- security exception or credential exposure;
- lane conflict;
- material architecture replacement;
- material new spending;
- constitutional governance change;
- reviewer disposition REJECT or INSUFFICIENT_EVIDENCE;
- unresolved critical/high risk;
- inability to reconcile GitHub and Supabase evidence.

Routine authentication, dependency, path, scheduler, allowlist, test, and documentation defects return automatically to the executor for correction.
