# Qwen Amendment to the Strategic Model and Agent Participation Standard

**Status:** DCS-DIRECTED CANDIDATE AMENDMENT  
**Date:** 2026-08-08  
**Applies to:** `governance/v7.1/STRATEGIC_MODEL_AND_AGENT_PARTICIPATION_STANDARD.md`  
**Scope:** Qwen participation only

## Amendment

Add Qwen to the `Media, voice, and interactive experience` participation class for:

- image generation and editing candidates;
- short-form video generation candidates;
- image-to-video and text-to-video candidates;
- story frames, visual concepts, motion studies, and campaign prototypes;
- multimodal review where the active surface demonstrates the required input and output.

Replace a volume-only interpretation of Qwen with this strategic inclusion statement:

### Qwen

Include Qwen as a strategic multimodal, image, video, coding, research, and cost-efficient production participant. DCS-confirmed Qwen Library usage and current screenshot evidence support continued image and video use. Exact surface, model, plan, quota, export, rights, automation, and quality status must be recorded per workflow.

Qwen may own raw generation and bounded implementation tasks when selected by the Execution Surface Router. Qwen may not self-approve, self-promote, establish its own lane authority, or convert interface visibility into VERIFIED readiness.

Quality calibration must measure:

- accepted-output rate;
- revisions per accepted asset;
- character and object consistency;
- visual artifact rate;
- motion and temporal consistency;
- prompt adherence;
- brand compliance;
- technical export compliance;
- cost per accepted image and approved second of video;
- reviewer time;
- rights and receipt completeness.

Workflow-specific approval points remain TBD and will be added as each Qwen production workflow is defined. Until then, concept selection, hero-asset selection, prototype acceptance, and public release remain DCS decision points.

## Boundary

This amendment changes Qwen's strategic participation slate. It does not establish Windows CLI installation, Universal Dispatch readiness, API authentication, Supabase registry readiness, or promotion authority.
