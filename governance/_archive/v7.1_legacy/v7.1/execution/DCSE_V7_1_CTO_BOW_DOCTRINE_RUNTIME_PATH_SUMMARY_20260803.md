# DCSE V7.1 CTO Summary: BOW Doctrine Runtime Paths

**Authority:** DCSE V7.1  
**Status:** `RUNTIME_MAPPING_REQUIRED`  
**Primary conversation doctrine:** `D04 Command Post Communications`

## CTO determination

Changing a governance label to V7.1 does not institute V7.1 doctrine at runtime. Runtime institution requires every conversation, directive, task, assignment, execution event, artifact, review, and promotion to identify the doctrines applied, the control each doctrine imposed, and the evidence proving compliance.

The canonical V7.1 manifest establishes startup, authority, lifecycle, evidence, review, fallback, and promotion rules. The Foundational Trilogy plan establishes an eight-phase completion loop. Neither currently provides a machine-enforced doctrine path for each BOW work package. The runtime implementation is therefore incomplete.

## V7.1 doctrine traversal

The retained doctrine path for governed operational work is:

1. `D01 Forward Thinking`: define objective, system effect, future state, and scale consequence.
2. `D02 Forward and Backward Chaining`: derive prerequisites backward from the goal and sequence execution forward.
3. `D03 AI Orchestration`: select capabilities, assign agents, define fallback, and prohibit unsupported execution claims.
4. `D04 Command Post Communications`: register conversation, turn, directive, task, event, handoff, receipt, and status.
5. `D05 Baseline Promotion`: baseline, implement, test, validate, correct, approve, activate, promote, and preserve rollback.
6. `D06 File System`: resolve canonical repository, branch, path, artifact identity, hash, and archive treatment.
7. `D07 Campaign Governance`: apply when work affects public campaigns, distribution, audience, or commercial launch.
8. `D08 Voice and Tone`: apply when output affects public or product-facing language.
9. `D09 Brand Identity`: apply when output affects visual identity, product identity, or branded experience.

Doctrines D01 through D06 are mandatory for every operational BOW. D07 through D09 activate when their subject matter is present.
