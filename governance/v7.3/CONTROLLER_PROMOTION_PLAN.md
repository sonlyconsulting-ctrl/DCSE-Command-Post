The current operative controller is v7.2 R5 as expressly designated by DCS; copied source R5 cannot be silently relabeled v7.3. The source snapshots under `reference/v7_2_mainline/` preserve R5 and current source history verbatim. Open PR #156/#158/#159/#160 are separately reviewed and may be included only after exact scope/authority decision. A GitHub PR merge or versioned folder alone never completes this promotion gate.
