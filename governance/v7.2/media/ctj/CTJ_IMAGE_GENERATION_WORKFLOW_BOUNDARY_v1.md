# CTJ Image-Generation Workflow Boundary v1

**Status:** CANDIDATE  
**Entity:** SC / Critical Thinker’s Journey  
**Relationship to ESCD:** External governed intelligence; not ESCD CF state  
**Governance floor:** DCSE v7.2

## Decision

The CTJ parent image, first-product image, logo-system prompts, source artwork, and image-generation workflow are SC/CTJ media assets. They SHALL NOT be inserted into the ESCD Conversation Flow (CF) as operational state, fixed prompt text, or default assistant behavior.

ESCD CF MAY retrieve a relevant summary or pointer when a task explicitly requires image-generation intelligence. Retrieval is read-only and task-scoped unless a separate SC/CTJ work order authorizes creative production.

## Participating image-generation surfaces

The governed workflow may use:

- Qwen 3.7 Plus / Qwen image-generation surface
- ChatGPT image generation
- Gemini image generation
- Google AI Studio image-generation surface

The provider/model list is capability metadata, not an ESCD CF instruction. Provider-specific prompts remain in the CTJ media prompt package.

## Parent and child asset model

The CTJ parent identity establishes:

- abstract cross-signature revealed through geometry and negative space;
- orbital/converging-path motif;
- navy, silver, muted gold, and white palette;
- mature cinematic and reflective visual language.

The first product is:

- product name: The Unified Path;
- subtitle: Consciousness, Clarity, and Free Thinking.

Future CTJ products inherit the parent system and change only product-specific name and subtitle unless a new brand decision is approved.

## Corrected creative constraint

The symbol must not be a literal cross, crucifix, monument, pole, tower, statue, or object rising from the ground. It must not depict Jesus Christ or any human. The cross-like meaning is an abstract, suspended visual revelation discovered through alignment, negative space, atmosphere, and converging paths.

The title treatment may use a restrained arc:

`THE CRITICAL THINKER’S JOURNEY`

Any generator-generated typography requires manual/vector QA before release.

## Retrieval contract for ESCD

When ESCD needs this intelligence, retrieve:

- the CTJ media prompt package;
- the parent/child asset manifest;
- the relevant source/reference image;
- current provider capability notes.

Return only the task-relevant instructions. Do not copy the full prompt package into CF memory or rewrite ESCD runtime state from creative content.

## Release controls

A generated image remains a candidate until:

- provenance and source references are recorded;
- provider/model and prompt version are recorded;
- no human, Jesus image, literal cross, or ground-rising object appears;
- parent/child visual consistency is checked;
- typography is corrected;
- black/white and small-size tests pass;
- Stripe or product-card size requirements pass;
- public-release authorization is recorded.
